# Akinator-Style Guessing Game

A Python guessing game inspired by Akinator, built using Python and Tkinter. The game asks users a series of questions and uses their answers to identify the person they are thinking of from a predefined set of candidates.

## Features

- Interactive graphical user interface built with Tkinter.
- Yes/no questions to narrow down possible candidates.
- Logic-based candidate identification.
- Restart functionality to play multiple rounds.

## Technologies Used

- Python
- Tkinter
- Conditional statements and logical operations

## How to Run

1. Ensure Python is installed on your computer.
2. Download or clone this repository.
3. Run the Python file:

   `python main.py`

## Purpose

Created to practice Python programming, logical reasoning, and GUI development through an interactive guessing game.
